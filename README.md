# Контрольная работа №2: Converse Shop (Bootstrap)

## Тема контрольной работы

«CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Учебный многостраничный сайт интернет-магазина обуви **Converse Shop**, разработанный с использованием CSS-фреймворка **Bootstrap 5**. Проект представляет собой полноценный адаптивный интерфейс с каталогом товаров, карточками, формами и интерактивными элементами.

## Используемый фреймворк и способ подключения

В проекте используется **Bootstrap 5**.
Фреймворк подключён **локально** (без использования CDN). Файлы библиотеки размещены в проекте:

- CSS: `css/bootstrap.min.css`
- JS: `js/bootstrap.bundle.min.js`

Собственные стили вынесены в файл `css/custom.css`, который подключается **после** Bootstrap для возможности переопределения стилей.

## Структура проекта

- index.html # Главная страница
- catalog.html # Страница каталога товаров
- product.html # Карточка товара
- order.html # Страница оформления заявки
- bootstrap.min.css # Локальный файл Bootstrap
- custom.css # Собственные стили и палитра
- bootstrap.bundle.min.js # Локальный JS
- README.md # Описание проекта
- .gitignore # Исключения для Git

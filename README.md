# Converse Shop — Контрольная работа №2

## Описание проекта

Converse Shop — учебный многостраничный сайт интернет-магазина обуви, разработанный с использованием CSS-фреймворка Bootstrap 5.

Сайт включает главную страницу, каталог товаров, страницу с подробной информацией о товаре и форму оформления заявки. Интерфейс адаптирован для разных размеров экранов.

## Используемые технологии

- HTML5 — структура страниц.
- CSS3 — собственные стили оформления.
- Bootstrap 5 — адаптивная сетка, навигация, карточки товаров, кнопки, формы и интерактивные компоненты.
- JavaScript Bootstrap — работа карусели, мобильного меню и аккордеона.
  Bootstrap подключён локально, без использования CDN.

## Страницы сайта

- **Главная (`index.html`)** — описание магазина, карусель изображений, преимущества и популярные товары.
- **Каталог (`catalog.html`)** — карточки товаров с изображениями, ценами и ссылками на страницы товара и заявки.
- **Товар (`product.html`)** — подробная информация о модели Converse Chuck 70, таблица характеристик и блок часто задаваемых вопросов.
- **Заявка (`order.html`)** — форма с полями для контактных данных, выбора товара и комментария.

## Особенности реализации

- Адаптивная сетка Bootstrap 5.
- Навигационная панель с мобильным меню.
- Карточки товаров с ценами и метками.
- Карусель изображений на главной странице.
- Аккордеон с часто задаваемыми вопросами.
- Форма с обязательными полями и встроенной проверкой браузера.
- Собственные стили и фирменная цветовая палитра в `css/custom.css`.
- Локальное подключение файлов Bootstrap без CDN.
